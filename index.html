SOBRE MIM

Sou estudante de Ciência da Computação com foco em desenvolvimento de software, especialmente para aplicações web. Tenho experiência com Node.js e Java no backend, além de React com TypeScript no frontend. Na camada de dados, trabalho tanto com PostgreSQL quanto MongoDB, sempre escolhendo a tecnologia mais adequada ao contexto. Também possuo conhecimento em Python aplicado à análise e tratamento de dados.

Atualmente, atuo na área de suporte técnico, onde presto auxílio direto aos usuários e contribuo para a evolução dos sistemas sob a ótica de negócio. Esse contato constante com desenvolvedores me permitiu compreender melhor as decisões técnicas e os trade-offs envolvidos no desenvolvimento de software, além de fortalecer minha visão centrada no cliente. Busco sempre resolver problemas de forma eficiente, evitando soluções desnecessariamente complexas e, quando preciso, colaboro com o time de desenvolvimento para analisar melhorias em conjunto.

Ao longo da minha jornada, desenvolvi projetos acadêmicos e pessoais voltados ao aprendizado prático — todos documentados no meu GitHub. Um dos principais foi o Investress, uma aplicação criada para simular cenários de estresse em investimentos e analisar possíveis perdas em momentos de crise. Nesse projeto, utilizei Java com Spring Boot no backend, PostgreSQL no banco de dados e React com TypeScript no frontend.

Tenho facilidade em aprender, me adaptar e trabalhar em equipe, sempre valorizando a troca de ideias e a comunicação clara. Encaro desafios como oportunidades de crescimento e tenho grande motivação em resolver problemas reais de forma eficiente.
